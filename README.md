# Kitsune releases

Installers and updates for the Kitsune logic analyzer and oscilloscope: the Windows app, and the firmware for the Kitsune board.

- **New install:** download the installer from the latest release on the [Releases](https://github.com/xEagless/kitsune-releases/releases) page.
- **Updates:** the Kitsune app checks here and updates itself. Each app release carries the matching board firmware, and the app offers to update your Kitsune when it connects.

This repository holds release files only. The source code is not published.
